## Get started in three steps

Set up your clinic and start managing patients, appointments and treatments.

### Step 1: Accessing the system

<AccordionGroup>
  <Accordion icon="user-check" title="Sign in to OCLÜ">
    Go to your custom URL (`yourclinic.oclucrm.com`), the one you chose when you signed up.

    - Use the email and password your administrator set up for you
    - If it's your first time, follow the sign-up flow described in **Getting started**
  </Accordion>
  <Accordion icon="gear" title="Initial setup">
    If you're the main administrator, before using the rest of the system it's a good idea to go through the **Administration** module:

    1. Fill in your clinic's details (Clinics)
    2. Create your team's users (Staff)
    3. Add your treatments and prices (Treatments)
    4. Set each clinician's working hours and days

    <Tip>You'll find all the details in the **Administration** module guide.</Tip>
  </Accordion>
</AccordionGroup>

### Step 2: First steps for your role

<AccordionGroup>
  <Accordion icon="user-doctor" title="If you're a Doctor">
    Start with the patient's file and the odontogram:

    1. Go to **Patients** → add or search for a patient
    2. Open their record → **Clinical record** tab → **Odontogram**
    3. Record diagnoses and create treatment planning
    4. Check your schedule for the day in **Calendar**

    <Tip>The odontogram is your main diagnostic tool.</Tip>
  </Accordion>
  <Accordion icon="user-tie" title="If you're a Secretary">
    Focus on the administrative side:

    1. Book appointments from **Calendar**
    2. Create **Treatment plans** from the patient's record
    3. Record payments from the patient's **Balance** tab
    4. Import patients from Excel if you have an existing database

    <Tip>The home screen is your control center: it shows today's appointments without having to open the Calendar module.</Tip>
  </Accordion>
  <Accordion icon="shield-check" title="If you're an Administrator">
    Set up the whole system from the **Administration** module:

    1. Create users and assign them a role
    2. Set up their specific permissions
    3. Add your treatments and price lists
    4. Set up the labs the clinic works with

    <Tip>The initial setup determines how organized the rest of the system will be.</Tip>
  </Accordion>
</AccordionGroup>

### Step 3: Basic workflow

<Accordion icon="workflow" title="Typical patient visit">
  1. **Front desk**: search for or create the patient
  2. **Visit**: record medical background and clinical notes in the clinical record
  3. **Diagnosis**: use the odontogram to mark findings
  4. **Treatment plan**: create a treatment plan with the treatments needed
  5. **Scheduling**: book the next appointment if needed
  6. **Payment**: record the payment from the patient's Balance
  7. **Follow-up**: add the clinical note for each visit

  <Tip>This workflow adapts to any type of treatment.</Tip>
</Accordion>
